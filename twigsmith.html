    Quick Help

    What is Twig? Twig is a modern templating engine for PHP. It allows you to create dynamic templates using logic and data injection.

    Common Twig Syntax:

    • {% if condition %}: Start a conditional block.
    • {% elseif condition %}: Add a secondary condition.
    • {% else %}: Add a fallback block.
    • {% endif %}: End a conditional block.
    • {% for item in list %}: Start a loop to iterate over items.
    • {% endfor %}: End a loop.
    • {{ variable }}: Output a variable's value.

    How to Use DynamicTwigGen:

    1. Enter a Twig condition (e.g., attendee.ticket_name == "VIP").
    2. Specify a field label for context.
    3. Write the desired Twig output.
    4. Click "Generate Twig Code" to see the result.
    5. Use predefined templates for inspiration or quick setups.
    6. Export the generated Twig code as a .twig file if needed.
