Getting Started with JSnippetGen

JSnippetGen is a code generator for handling custom JS requests for common Gevme-Reg use-cases. This guide will walk you through using each feature step by step.

Note: Make sure you're logged in before starting using the passphrase provided to you. You can use the "Log out" button in the top right when you're done.

DOM Manipulation

Generate code for manipulating DOM elements.

How to Generate DOM Manipulation Code:

  1. Select "DOM Manipulation" from the main category dropdown
  2. Choose one of the following actions from the "Select DOM Action" dropdown:
    • Change Style: Modify CSS properties
      Input format: #myDiv, color: red
      Explanation: First part is the selector, second part is the CSS property and value
    • Add Content: Insert HTML content
      Input format: #myDiv, Hello World!
      Explanation: First part is the selector, second part is the content to add
    • Remove Element: Delete elements
      Input format: #myDiv
      Explanation: Just enter the selector of the element to remove
    • Event Listener: Add event handlers
      Input format: #myButton, click
      Explanation: First part is the selector, second part is the event type
  3. Click "Generate Code" to create the JavaScript code

Complex CSS Styling

Generate JavaScript code for dynamic CSS manipulation.

Available Options:

  1. Enter CSS Selectors:
    Input format: #id, .class, div
    Explanation: Comma-separated list of CSS selectors
  2. Enter Base Styles:
    Input format: {"color": "blue", "background-color": "lightgray"}
    Explanation: JSON object with CSS properties and values
  3. Enter Event-Based Styles:
    Input format: {"click": {"transform": "scale(1.2)", "color": "red"}}
    Explanation: JSON object with event types and their style changes
  4. Add Transitions:
    Input format: all 0.5s ease
    Explanation: Standard CSS transition value

API Handling

Generate code for API requests.

Steps to Generate API Code:

  1. Select "API Handling" from the main dropdown
  2. Choose the HTTP method:
    • GET:
      Input format: https://api.example.com/data
      Explanation: Just enter the API endpoint URL
    • POST/PUT:
      Endpoint format: https://api.example.com/data
      Payload format: {"key": "value"}
      Explanation: Enter both the endpoint URL and JSON payload
    • DELETE:
      Input format: https://api.example.com/data/123
      Explanation: Enter the API endpoint URL with resource ID

Form Validation

Generate form validation code.

Available Validation Types:

  1. Check Empty Fields:
    Input format: myForm
    Explanation: Enter the form's ID
  2. Email Validation:
    Input format: emailInput
    Explanation: Enter the email input field's ID
  3. Custom Validation:
    Input format: myForm, if(value.length < 8) { alert('Too short!'); }
    Explanation: Enter form ID and custom validation logic

Attendee Forms

Generate code for handling registration forms.

Available Features:

  1. Prevent Copy-Paste in Confirm Email:
    Input format: attendee[confirm_email]
    Explanation: Enter the confirmation email field name
  2. Email Address Validation:
    Input format: attendee[email], attendee[confirm_email]
    Explanation: Enter both email field names
  3. Convert Form to Multi-Step:
    Input format: .gf-item
    Explanation: Enter the class name for form items
Tip: When using the multi-step form conversion, make sure all form fields have the specified class for proper functionality.
